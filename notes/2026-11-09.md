## 精读 1/2｜基于牙髓生物标志物与临床指标预测活髓治疗预后：一项前瞻性临床研究

- 期刊：International endodontic journal（B 级）｜2026-11-06
- 设计：队列｜样本：未提及
- 评分：46.0/100
- 链接：https://pubmed.ncbi.nlm.nih.gov/42995471/

**一句话**：前瞻性队列检测牙髓生物标志物预测活髓治疗结局。

**研究问题**：在活髓治疗中，临床参数和牙髓局部生物标志物能否比传统「可逆/不可逆」诊断更准确地预测治疗结局？

**设计与样本**：单中心、前瞻性队列研究，纳入50颗成熟恒牙行部分或全牙髓切断术，随访1年，比较成功与失败组的临床与分子指标差异。；50颗成熟恒牙，诊断为可逆性或不可逆性牙髓炎，未说明来源细节

**关键证据**

- 传统可逆/不可逆牙髓炎分类对VPT预后无预测价值 —— 两组间p>0.05，无明显统计学差异
- 冷测反应时间延长是失败预测因子 —— 失败组显著高于成功组，ROC AUC=0.764，界值>30s时p=0.014
- 术中出血时间延长是失败预测因子 —— 失败组显著高于成功组，ROC AUC=0.809，界值>350s时p=0.004
- 炎症介导的生物标志物谱与失败相关 —— 失败组MMP-1、MCP-1、IL-1β、MDA、MMP-12、TGF-β、TNF-α水平显著升高（p<0.05）

**效应量**：冷测反应时间AUC=0.764；出血时间AUC=0.809；具体效应量（OR、HR等）摘要未说明

**与我的课题**：与q4最相关：牙髓组织的免疫微环境状态（炎症-氧化应激平衡）如何决定组织再生结局。本研究提供了从种植/牙周方向可迁移到牙髓方向的机制框架——即宿主免疫应答的质量决定再生成败。同时间接涉及q1中巨噬细胞极化相关通路。

**局限**：样本量较小（n=50），且仅1年随访，无法评估长期稳定性及迟发失败模式；未进行多变量联合建模，各标志物的独立贡献度与交互效应不清；ELISA检测的是单一时间点点采样，未能反映牙髓炎症动态演变过程

**可迁移**：可将「出血时间+冷测反应时间」简化临床指标作为快速预后筛查工具引入自己的课题；若研究方向涉及口腔软组织愈合，可借鉴其生物标志物panel策略（MMPs/TIMPs/细胞因子/氧化还原平衡维度）。

**三个追问**

- [ ] 该研究中MMP-1、MMP-12、TIMP-1的比例关系是否可推导牙髓基质降解-修复的动态平衡状态？原始数据中这些指标的比值是否有更强预测力？
- [ ] 出血时间的测定方法是否标准化？不同研究者之间的测量重复性如何？这一指标在多大程度上反映的是血管通透性而非单纯的出血量？
- [ ] IL-1β、TNF-α、MCP-1三者的协同作用是否意味着存在特定的促炎小胶质样或巨噬细胞活化表型？后续可否通过单细胞分型验证这一假设？

**术语**：Vital pulp therapy (VPT) = 活髓治疗；MMP-1 / MMP-12 = 基质金属蛋白酶-1 / 基质金属蛋白酶-12；TIMP-1 = 组织抑制剂金属蛋白酶-1；TAS / TOS = 总抗氧化活性 / 总氧化应激；SOD = 超氧化物歧化酶；MDA = 丙二醛（脂质过氧化标志物）

## 精读 2/2｜微层叠氧化锆全瓷冠的磨损性能及基于不同方法的集成扫描与外部扫描工作流程的比较

- 期刊：Clinical oral investigations（B 级）｜2026-11-07
- 设计：队列｜样本：n=8
- 评分：20.7/100
- 链接：https://pubmed.ncbi.nlm.nih.gov/42995302/

**一句话**：体外模拟咀嚼测试微层氧化锆冠磨损，STR组体积损失最低。

**研究问题**：不同微层叠陶瓷品牌（CER/IQS/MIY/STR）的ML氧化锆冠在模拟咀嚼下的体积损失是否存在差异？扫描工作流程（集成 vs 外部激光）是否会导致体积损失的系统性高估或低估？

**设计与样本**：体外模拟咀嚼试验：四种ML陶瓷+一种MZ对照，60万次循环加载，在多个时间点采集表面数据进行纵向比较。；n=8 per ceramic for ML crowns, n=3 for MZ (negative control)

**关键证据**

- STR品牌的ML冠体积损失显著低于MIY和IQS —— p ≤ 0.018，基于线性混合效应模型的边际均值比较
- 体积损失随咀嚼循环次数递增 —— p < 0.001，在0、60000、120000、600000 cycle时间节点均记录
- 单块氧化锆（MZ）无可见磨损 —— No measurable volumetric loss observed
- 扫描工作流显著影响体积损失估计值，且存在材料与工作流的交互效应 —— p ≤ 0.001；外部激光扫描给出更高的体积损失估计，p ≤ 0.048

**效应量**：未报告具体效应量数值及置信区间

**与我的课题**：与 q4 相关：生物材料（ML氧化锆各品牌）的表面/结构特性直接影响磨损行为；提供证据——不同ML成分虽同为'氧化锆冠'类别，但磨损性能差异显著，材料选择不是中立的。

**局限**：体外模拟环境无法复制真实口腔的温湿度循环、唾液成分、咬合力变化，60万次循环对应的临床时间尚不明确；各组样本量小（ML n=8，MZ仅n=3），统计效能受限，尤其是MZ仅作阴性对照而未纳入建模

**可迁移**：① 线性混合效应模型处理纵向重复测量数据的分析框架；② 多时间点表面数据采集策略用于跟踪磨损动态；③ 对比两种扫描工作流的方法学验证思路可用于其他数字化修复流程研究。

**三个追问**

- [ ] 四个ML品牌（CER/IQS/MIY/STR）各自的内部层状结构成分是否有公开数据？能否从制造配方角度解释STR为何磨损更低？
- [ ] 60万次循环对应的等效临床使用年限是多少？该研究未提及，需通过文献查找咀嚼频率换算。
- [ ] 外部激光扫描高估磨损的幅度是否在后续研究中给出了具体的偏差百分比？还是仅报告了统计显著性？

**术语**：Microlayered (ML) zirconia = 微层叠氧化锆：通过多层叠加不同着色/透明度的氧化锆坯体实现美学效果的材料；Monolithic zirconia (MZ) = 单块氧化锆：整体由单一氧化锆材料构成，无表层着色层；Scanner-integrated workflow = 扫描集成工作流：内置于椅旁口扫设备或实验室扫描仪的直接测量方案；External laser-scanning workflow = 外部激光扫描工作流：将修复体单独放置于独立高精度激光扫描仪进行表面数据采集的方案；Linear mixed-effects model = 线性混合效应模型：适用于纵向重复测量数据的统计分析方法
